# 03-项目架构与设计

# 一、整体定位

Unity3D游戏客户端，主要使用**C#**。

# 二、架构图速览

## 核心框架

> 根目录 `Assets/Scripts` 是项目最初始的底层目录，以下树状图为当前真实结构，右侧为职责注释

```text
Assets/Scripts                                 项目底层（最初始目录）
├── Framework                                  框架层：与玩法无关的通用基础设施
│   └── QTower                                 框架主命名空间 Framework.QTower
│       ├── QTower.asmdef                      独立程序集，引用 Utils / Addressables / UniTask
│       ├── EventManager.cs                    全局事件总线：RegisterEvent / UnregisterEvent / PublishEvent
│       ├── Common                             基础设施
│       │   ├── Singleton.cs                   纯 C# 单例基类，Init / Tick / Destroy 三段生命周期
│       │   ├── Defines
│       │   │   ├── EventDefines.cs            跨模块事件名常量
│       │   │   └── UIDefines.cs               UI 的 Addressables 地址常量
│       │   ├── Res
│       │   │   └── ResManager.cs              Addressables 加载卸载、实例管理、对象池
│       │   └── Sound
│       │       └── SoundManager.cs            BGM、一次性音效、循环音效播放
│       ├── MVC                                框架核心：控制器 + 视图
│       │   ├── UIManager.cs                   UI 注册、加载、缓存、显示、隐藏、关闭
│       │   ├── Type
│       │   │   └── ControllerType.cs          全局控制器类型标识（None / Game）
│       │   ├── Data
│       │   │   └── UIData.cs                  UI 注册数据：Address / Parent / Controller / SortingOrder
│       │   ├── Controller
│       │   │   ├── BaseController.cs          控制器基类，生命周期 + 事件托管 + OnView* 回调
│       │   │   └── ControllerManager.cs       控制器按类型注册，统一 Tick 驱动，逆序销毁
│       │   └── View
│       │       ├── UIBase.cs                  运行时 UI 视图基类，Init / Open / Hide / Close
│       │       └── UIItemBase.cs              UI 子项基类，节点缓存与显隐控制
│       └── Editor                             编辑器层：仅编辑器编译，不进包体
│           ├── QTower.Editor.asmdef           includePlatforms Editor，仅引用 QTower
│           ├── Controller
│           │   └── BaseEditorController.cs    编辑器控制器基类，统一生命周期与更新驱动
│           └── View
│               └── UIBaseEditor.cs            编辑器 UI 视图基类，统一生命周期与事件订阅
├── Module                                     模块层：可复用玩法系统，不依赖具体界面
│   └── Timer
│       ├── TimeManager.cs                     对外门面，Register / Cancel / ClearAll / Tick / Destroy
│       ├── GameTimer.cs                       延迟与循环计时任务集合
│       └── GameTimerData.cs                   单个计时任务数据
├── Game                                       业务层：组合根与场景入口
│   ├── GameScene.cs                           MonoBehaviour 入口，找 UIRoot、DontDestroyOnLoad、驱动 Tick
│   ├── GameApp.cs                             组合根 Singleton，装配 Time / Controller / UI 三大管理器
│   └── GameController.cs                      场景控制器，注册默认界面、订阅事件、销毁时反注册
├── UI                                         业务界面层（当前为空目录，待玩法填充）
└── Utils                                      工具层：无状态扩展与轻量工具，零依赖
    ├── Utils.asmdef                           独立程序集，references 为空
    ├── log
    │   └── QLog.cs                            日志封装，Release 构建自动抹除
    ├── Find
    │   └── HierarchyFindTool.cs               组件与 Transform 子节点查找扩展
    └── Timer
        └── DurationTimer.cs                   无事件轻量计时器，负责局部时间进度计算
```

## 程序集边界

| 程序集 | 覆盖目录 | 依赖 |
| --- | --- | --- |
| `QTower` | `Framework/QTower/`（不含 `Editor/`） | `Utils`、`Unity.Addressables`、`Unity.ResourceManager`、`UniTask`、`UniTask.Addressables` |
| `QTower.Editor` | `Framework/QTower/Editor/` | 仅 `QTower`，`includePlatforms` 限定 Editor |
| `Utils` | `Utils/` | 无，零依赖叶子层 |
| `Assembly-CSharp` | `Game/`、`Module/`、`UI/` | 未建 asmdef，自动引用以上全部程序集 |

## 依赖方向

```text
             Game                业务层：组合根与场景入口
           /      \
        UI        Module         UI 目前为空，Module 现有 Timer
           \      /
              v
      Framework/QTower   <   QTower/Editor
              |                编辑器层只依赖 QTower，不进包体
              v
            Utils                工具层：零依赖
```

- 引用只允许自上而下：业务层 → 框架层 → 工具层
- 禁止 `Framework/QTower`、`Utils` 反向引用 `Game`、`UI`、`Module`
- 新增玩法系统放 `Module`，新增界面放 `UI`，通用能力放 `Framework/QTower`

## 启动链路

```text
GameScene.Awake
  ├─ HierarchyFindTool.FindSceneRoot(UIRoot)
  ├─ DontDestroyOnLoad(GameScene + UIRoot)
  ├─ GameApp.Instance.Init()  ->  new TimeManager / ControllerManager / UIManager
  └─ GameApp.UIManager.SetRoot(uiRoot)

GameScene.Start
  └─ ControllerManager.Register(ControllerType.Game, new GameController())

GameScene.Update
  └─ GameApp.Instance.Tick(deltaTime)
        ├─ TimeManager.Tick
        └─ ControllerManager.Tick  ->  BaseController.Tick

GameScene.OnDestroy
  └─ GameApp.Instance.Destroy
        UIManager -> ControllerManager -> TimeManager -> ResManager
```
