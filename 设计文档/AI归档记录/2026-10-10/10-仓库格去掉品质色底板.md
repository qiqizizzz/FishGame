# FishGame 商店：仓库格别再画一块品质色底板，用架子自己那张

## 一、记录范围

一处外观修正，不加逻辑：**暂存架（仓库）里放了东西的格子，整格被染成一块品质色实心板**，把架子自己的默认栏底盖掉了。改成一律沿用架子默认那张底，物品只往上贴图标。

顺带记一个取证方法：**「这块灰底是谁画的」有三个候选（底板 Image / 图标自带底 / 额外的第二层背景），逐个排掉才敢动手**。

## 二、用户诉求原话

> 「然后就是仓库这边买的东西别带这种背景啊，不是有暂存架默认的物品栏吗」

（配图：仓库第一个格子里一枚圆形图标压在浅灰方块上，右边四个空格子是米色圆角栏底）

## 三、取证：那块灰底是格子的根 Image

`Storage_0` 整棵子树只有**一个**背景层（探针 dump 预制体，逐节点列 Image 的 sprite/color/raycast）：

| 节点 | active | Image | 说明 |
| --- | --- | --- | --- |
| `Storage_0`（根） | True | sprite=`Square Buttons 26x26_1`，color=(1,1,1,**0.24**) | 就是架子默认那张米色圆角栏底，0.24 = `EmptyColor` |
| `Node_ClothShape` | True | 子 `Cell_Template` 22x22（默认 inactive） | 布的异形预览 |
| `Txt_Label` | False | — | 无图标时才用 |
| `Img_Icon` | False | sprite=NULL，color 白 | 物品图标 |

**没有第二层底**，所以灰板只可能是根 Image 变了脸。翻 `UIShopSlotItem.SetStored()`：

```csharp
m_bgImage.sprite = isCloth ? CellSprite : null;   // 装备走 null
m_bgImage.color  = isCloth ? EmptyColor : qualityColor;
```

`Image.sprite = null` 在 UGUI 里画的是**整块纯色矩形**（内置白图），品质色一到三级走白蓝紫（`UIShopQuality.TierColor`），tier 1 的 `White` = **(0xC9, 0xCD, 0xD2)** —— 正是截图里那块浅灰。角是直角、铺满整格，也对得上。

另外两个候选是这么排掉的：

- **图标自带底？** 采样全部 item 图标 sprite rect 的四角 alpha（把 PNG `ImageConversion.LoadImage` 成可读副本再 `GetPixel`，因为导入设置是不可读）。`fish_and_items_*` 32x32 四角全 0.00，`item2_*` 16x16 四角 0 或 1（像素画本身形状，不是底板），`rod_t*` 48x48 四角全 0.00。**没有一个带浅灰方块底**
- **背包里也有这毛病？** `UIShopItemView` 里搜 `sprite = null` 只命中 `SetLocked()`（背包锁格，本来就该是纯色暗块），装备在背包上是 sprite-only。所以这是**仓库格独有的**，不用连改两处

## 四、改法

`D:\CCodes\unity\FishGame\Assets\Scripts\UI\Shop\UIShopSlotItem.cs` 的 `SetStored()` 两行去掉三元：

```csharp
// 底格一律用空格那张淡底，物品只往上贴图标，不再整块染品质色把架子默认栏盖掉
// 布也不染满格，那样只剩一块方块，占几格什么形全读不出来，另走异形
m_bgImage.sprite = CellSprite;
m_bgImage.color  = EmptyColor;
```

**布那条路本来就是这个写法**（`CellSprite` + `EmptyColor` + 上面叠异形），所以这次是把装备拉齐到布的待遇，不是新发明一套。`raycastTarget = true` 不动 —— 装了东西才吃射线，点一下取回和拖上网格都靠它。

同步改了两处注释口径：文件头的「没图标才整格染品质色」、`SetStored` 的 `<summary>`。
## 五、取舍：架子上的装备不再一眼看出档位

去掉底板确实少了一个信息通道，记清楚**品质色现在还在哪四处生效**，别以为全丢了：

| 位置 | 用法 | 状态 |
| --- | --- | --- |
| 布的异形逐格 | `m_clothShape.Setup(..., qualityColor, ...)` | 保留，布的颜色就是品质色 |
| 拖出架子的幽灵格 | `m_qualityColor` → `UIShopShapeGhost.Build()` | 保留 |
| 无图标时的名称字色 | `UIShopQuality.LabelColor(qualityColor)` | 保留 |
| 商品卡与详情小窗文字 | `UIShopQuality` 各档色 | 保留 |

**装备在架子上认档位，改成点一下看小窗标题**（`UIShopGoodsName.Of()` 出的「快解刀 Ⅰ」，罗马数字在 MaoKen 里有字，见 9 篇第六节）。图标本身每件都不同，架子上「这是什么」仍然一眼可辨，只是「几档」要按一下。

如果之后觉得档位不够醒目，正解是**给图标加个小角标或描边**，而不是再把整格染成色块 —— 那正是这次要去掉的东西。
