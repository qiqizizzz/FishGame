## 四、改了什么

### 4.1 叠加格抄真格子的底图（UIShopItemView）

- `Setup` 尾部加一个参数 `Sprite cellSprite`，存进新字段 `m_cellSprite`
- `showBlock` 里给两张脸都赋底图：暗边 `rim.sprite = m_cellSprite`，亮面 `face.GetComponent<Image>().sprite = m_cellSprite`
  亮面仍按 `RIM_THICKNESS` 四周内缩，所以凹槽还是两侧暗边拼出来的那套
- `UIShopPanel.cs:941` 把面板里**已有**的 `m_cellSprite` 传进去 —— 它读自第一格的 `EmptyCellSprite`（`UIShopPanel.cs:269`），
  和 `GhostCellSprite` 同一个来源，三处（真格子 / 幽灵 / 叠加格）从此一张图

### 4.2 指针还在网格内就整块吸附（OnDrag 重写，218-241 行）

```csharp
Vector2 free = pointerInGrid(eventData) - m_grabOffset;

// 指针还在网格内就把包围盒左上角吸附到整格，抓着手感那点偏移照算，手指底下那一格不会跳走
if (m_host.TryPointerCell(eventData.position, out _, out _))
{
    m_rect.anchoredPosition = new Vector2(Mathf.RoundToInt(free.x / m_pitch) * m_pitch,
        Mathf.RoundToInt(free.y / m_pitch) * m_pitch);
    setBlocksVisible(true);
}
else
{
    // 拖到网格外就脱离格子跟着手走，有图标的把叠加格收掉只剩图标，和幽灵一个处理
    m_rect.anchoredPosition = free;
    setBlocksVisible(!m_hasIcon);
}

// 每挪一格都要重新问一遍宿主，盖得住与缺格子的分界得跟着手指走
refreshDragTint();
```

吸附的是**包围盒左上角**，正好是 `showBlock` 摆格子用的那个原点，所以吸附完每一格都和真格子严丝合缝。
`OnEndDrag` 与 `refreshDragTint` 的换算一行没改：位置既然已经落在整格上，四舍五入是恒等的，
看见的红格子就是松手真摆不上的格子，所见即所得。

### 4.3 🔴 符号坑：y 不能取负

`anchoredPosition.y` 本来就是负的（网格向下为负），吸附写成 `RoundToInt(free.y / m_pitch) * m_pitch` 就对了；
一度写成 `-free.y / m_pitch`，行号直接翻负，探针实测落点变成 `drop=(2,-3)`。已修，别再手滑。
