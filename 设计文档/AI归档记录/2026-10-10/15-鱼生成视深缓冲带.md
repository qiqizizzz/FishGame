# FishGame 鱼生成：可玩深度以下补一段视深缓冲带

> 上一轮：2026-10-10/14-布定价上调与深层闪避微缩鱼.md　　本轮日期：2026-10-10　　基线 HEAD：8151d2c「修复错字」

## 一、用户诉求原话

> 「25m 之外的海域我看不到有任何鱼生成啊，你不能就是钓杆只能钓 25m 之外的就在屏幕那边不显示了啊
> （至少玩家能看到一半屏幕都没有鱼，你至少得搞个缓冲区啊）」

## 二、取证：这不是错觉，是 13 号文档里那条 B5 余量留下的洞

`FishingCameraRig` 实测参数（探针 `Temp/cam_probe.txt`）：正交半高 **4.5**、aspect **0.563**（竖屏）、
`LookAheadMeters` **2.05**、`SurfaceY` 0。镜头中心 = 钩子 y + 2.05，所以

```
屏幕底边深度 = 钩子深度 + (4.5 - 2.05) = 钩子深度 + 2.45
屏幕顶边深度 = 钩子深度 - 6.55
可视窗总高 = 9 m
```

而 `FishSpawnService` 这边：

```csharp
m_reachableDepth = min(ShaftDepth, LineLength)      // 开局 25
spawnDepthCeiling = m_reachableDepth - 3            // 22  ← 生成硬上界
maxDepth = min(m_reachableDepth, hook + 30)         // 25  ← 回收硬上界
targetForSlice: sliceTop >= reachable → 0           // 25 m 以下整片不铺
```

钩子沉到线长终点 25 m 时：屏幕显示 **18.45 → 27.45 m**，鱼只存在于 22 m 以上。
**22 → 27.45 这 5.45 m 是死水，占 9 m 屏幕的 60.6%**，正好是玩家说的「半屏没有鱼」。
线长买满 53.5 m 时同理（50.5 → 55.95 空），每一趟下潜触底都必然出现，不是偶发。

13 号文档的 B5 把生成上界压在 reachable 以下 3 m 是为了防「摆动越界被回收 → 白转对象池」，
但当时窗口上界也一起压在 reachable，于是把「省实例」省到了玩家的视野里。省实例的前提是那块水看不见，
而它恰恰看得见。

## 三、改法：生成/回收上界跟镜头走，配平仍然跟鱼线走

`Assets/Scripts/Module/Fish/Service/FishSpawnService.cs` 七处，一个字段两行常量串起来：

| 位置 | 改动 |
| --- | --- |
| 常量 | `VIEW_BUFFER_BELOW = 8f`（2.45 可视 + 3 摆动余量 + 2.55 松量）、`BUFFER_FISH_PER_SLICE = 2` |
| 字段 | 新增 `m_viewCeiling`，在 `refreshReachableDepth()` 里与 `m_reachableDepth` 一起算，实时跟线长 |
| `Stream` | 回收上界 `min(m_viewCeiling, hook + STREAM_AHEAD + SPAWN_DEPTH_MARGIN)` |
| `populateInitial` | 末片 `sliceIndexOf(m_viewCeiling)` |
| `spawnDepthCeiling` | 由 `reachable - 3` 改成 `viewCeiling - 3` |
| `targetForSlice` | 越出 reachable 的切片不再返回 0，返回 `BUFFER_FISH_PER_SLICE`；越过 viewCeiling 才返回 0 |
| 文件头/注释 | 补上缓冲带那段说明 |

三个关键决定：
1. **密度配平不动**。可玩范围内的切片继续走 `BaseFishPerSlice × SampleDensity(depth, reachable)`，
   缓冲区用独立常数 2 条/片。收益曲线、回合目标、13 号那套归一全都保持原样。
2. **回收上界比生成上界再宽一份摆动余量**（`+ SPAWN_DEPTH_MARGIN`）。钩子在水面时
   `hook + 30` 恰好等于生成上界 30，贴着 30 出生的鱼一摆就越界 → 收→补→收空转。加完余量后
   回收 33 / 生成 30，B5 那个坑不会再从另一头冒出来。
3. **缓冲区是视深概念，不是新玩法层**。钩子本身仍然被 `LineLength` 钳在 25 m，
   `HookViewController.MaxDepth` 一行没动，所以缓冲区里的鱼默认钓不到 —— 它顺带变成
   「再买一级线长就能往下够」的视觉预告。

## 五、已知副作用（等实机判断，没提前写守卫）

鱼钩在触底瞬间会停在 `LineLength` 处，而缓冲区最浅的一条鱼可以生在 25.0 m，
判定距离 = `radius 0.15 + 鱼身半高 + TOUCH_TOLERANCE 0.1`，鲈鱼这类大个儿约 0.5 m。
所以**线长终点正下方半米内的大鱼可能被白捡一条**（回收段挂上，不算失误）。
- 概率低：要同时满足钩子触底 + 那条鱼漂到终点下方 0.5 m 内
- 观感上说得通：鱼身已经贴到钩子，不是「隔空吸鱼」
- 如果实机觉得别扭，加一行守卫即可：`tryPickDepth` 里对 `sliceTop >= reachable` 的切片把深度下限压到 `reachable + 0.8`，或者让 `FishDetectionService` 直接忽略 `Depth > LineLength` 的鱼
