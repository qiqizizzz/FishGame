## 四、关键实现

### 4.1 长轴怎么量出来的（UIShopIconFit.analyze 166-243）

- 读 `sprite.textureRect` 那一块的 `GetPixels32()`，`alpha >= 26` 才算实心，抗锯齿边不参与
- 对全部实心像素做**以 alpha 为权重的协方差矩阵**，长轴角 `Axis = 0.5*atan2(2*covXY, covXX-covYY)`
- 各向异性度 `Aniso = sqrt(major/minor)`：小于 `MIN_ANISOTROPY = 1.6` 就当这团东西没有朝向可言，硬转只会更怪（硬币、线轴就是这类）
- 每个 `Sprite` 只读一遍，读失败也记一笔 `Usable=false`；摆法再按 `columns*64+rows` 缓存，重铺背包不回头重算

### 4.2 转角与缩放（solve 246-276）

- 盒子竖着（`boxH > boxW*1.02`）→ `angle = 90 - Axis`；盒子横着 → `angle = -Axis`；**方盒子不转**，原样摆最合画师本意
- `fold()` 把角度折进 `(-90, 90]`：长轴没有头尾，不折就会把好好的东西倒过来插进格子
- 关键：**缩放用的是旋转之后的真实外接范围**，不是贴图方框。斜着画的素材转完会变瘦，只看贴图框会把它算小一半
- `scale = min(boxW/extentW, boxH/extentH)`，再夹一道 `MAX_SCALE = 32`（只防实心像素几乎没剩下时的除法溢出，缩放本身已被盒子卡住）
- `size = 素材像素尺寸 * scale`（保持素材原始宽高比），`offset = -center*scale` 把画面重心拉回盒子正中
- 读不出像素时 `analyzed=false` → 矩形铺满盒子 + `preserveAspect=true`，交给 Image 自己等比

### 4.3 🔴 修掉的溢出 Bug（extent 299-306）

`points` 存的是像素**中心** `(x+0.5, y+0.5)`，取 AABB 只覆盖中心范围，比实际绘制内容少一圈 →
每个图标（连黑描边）会往包围盒外多探约 1 个素材像素。补上投影厚度：

```csharp
// 每个实心像素是一格见方的方块，只按像素中心取范围会少算一圈边
float pad = Mathf.Abs(cos) + Mathf.Abs(sin);
width  = maxU - minU + pad;
height = maxV - minV + pad;
```

转正时 pad = 1，斜 45° 时 pad ≈ 1.414，正是那个 1×1 像素方块在两个方向上的投影。

### 4.4 为什么必须先关 Tight 裁切

`spriteMeshType = Tight` 会把网格裁到实心范围，此时 `rect != textureRect`，按 rect 反推像素位置就错了。
7 张源图已改成 `FullRect`，实测 14 件图标全部 `rect == textureRect`。

### 4.5 拖拽改拖图标（诉求 2）

- `UIShopItemView.applyDragVisual`：`setBlocksVisible(!m_hasIcon || m_isDragging)`，图标 `active = m_hasIcon` —— 图标一路亮着，格子只在拖起来时垫在底下当叠加层
- `IShopBackpackHost.IsPreviewCellValid(item, col, row)` 逐格回答放不放得下（越界 / 底下没布 / 被别的装备压住），`dragging` 自己占的格不计冲突，从暂存架拖来时它压根不在网格上
- `UIShopShapeGhost.tintCells`：盖得住 → 品质色压深；缺格子 → 红色压深；两者都只当半透明叠加，图标永远不缺席
- 指针还在网格外时走 `FollowPointer`，只留图标跟着手，不进格子区
- 图标矩形比盒子宽的那些留白是**透明**的：`alphaHitTestMinimumThreshold = 0.1` 让它不吃点击，点空白处照样是拿底下的布

| 探针 | 结果 |
| --- | --- |
| 42 个 tier 组合跑 UIShopIconFit.Compute | `analyzed` 全 true，**兜底 0 个** |
| 渲染图逐条带肉眼复核（4 条） | 所有图标完整落在红框内，无一处探出 |
| 溢出最明显的 tile 放大 2x 复核 | 黑描边与红框之间仍有空隙，pad 修复生效 |
| rod_training(rod_t1_wood 48x48) Axis | ≈46.2°，素材本就画成左下→右上的斜放鱼竿，进竖盒转 +43.8° 变竖直，方向正确 |
| 转角分布 | 硬币/线轴/转环等 `Aniso<1.6` 一律 0°；鱼竿、假饵、羽毛钩子等在竖盒里 43.8°\~89.8° |

> ⚠️ 两个**曾经误判过、别再去"修"**的点：
> 1. 探针里 `rectAABB > box`（fill 可达 3.3）不是 Bug。画出来的内容 = `extent*scale\ ≤ box`；rect 比内容大是因为它必须保持素材原始宽高比，多出来的是透明留白
> 2. `MAX_SCALE` 从 4 改到 32 不是回归，缩放本来就被包围盒卡着
