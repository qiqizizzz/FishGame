## 四、关键实现

### 4.1 图标铺满 + 长轴转角（UIShopItemView.showIcon 291-326）

- 图标矩形不再是「居中留内缩」，而是 `sizeDelta = (columns*pitch, rows*pitch)`，锚点 `(0,1)`、轴心 `(0.5,0.5)`，
  `anchoredPosition = (columns*pitch*0.5, -rows*pitch*0.5)`，正好盖住整块包围盒，`preserveAspect = false`
- 转角由 `shouldRotateIcon(icon, columns, rows)`（328-347）算：盒子与素材**都**要有长短轴，且拧着来才转 90
  - `columns == rows` 直接不转（方盒子没有长轴可对）
  - `max(w,h) < min(w,h) * 1.2f` 视为方形素材，不猜朝向（这条是踩过坑补的：不加它，14 件方形图标在 1x2 竖盒里会被整体转倒，鱼竿变成横指）
  - 其余情况 `return (columns > rows) != (width > height)`
- 旋转的摆法：先把矩形自身摆成「躺着」的 `m_iconSize`（转 90 时取 `(rows*pitch, columns*pitch)`），再绕中心 `localEulerAngles.z = 90`，
  转完的世界外接框与不转时完全一致，实测逐例对齐（见 §五）
- 物品旋转 → 模型给的 cells 长短边互换 → `columns/rows` 互换 → 角度自动加减 90，正是用户要的那条规则
- `m_iconSize` / `m_iconAngle` 通过 `IconSize` / `IconAngle` 属性暴露给面板，飞行物照抄同一姿态

### 4.2 仅像素点击（createIcon 353-370）

- `image.raycastTarget = true; image.alphaHitTestMinimumThreshold = 0.1f;`
- 该阈值要求贴图 **Read/Write enabled**，否则 Unity 报错并退化成整块矩形都能点；7 张源图已全部开成 `isReadable=True`
- `filterMode=Point`：像素图按最近取点，顺带避免 `GetPixelBilinear` 从同 sheet 相邻子图吸色
- 底层 `(0,1)` 锚点的形状块 `Img_Block` 不吃射线，只有 `Img_Face` 吃；`m_hasIcon` 为真时平时整组底色块 `SetActive(false)`
- 工程内无 `.spriteatlas`/`.spriteatlasv2`（0 个），图标不会被自动打包到不可读的图集页上

### 4.3 拖起来才数格子（applyDragVisual 341-349）

- `m_isDragging` 由 `OnBeginDrag` 置真、`OnEndDrag` 置假，`OnDisable` 兜底复位（面板中途关掉走不到 OnEndDrag）
- 规则：`setBlocksVisible(!m_hasIcon || m_isDragging)` + 图标 `active = m_hasIcon && !m_isDragging`
- 所以有图标的装备平时只看得到一张图；没图标的（目前只有布 `ClothPieceDef.Icon => null`）底色块就是它本身，任何时候都亮着

### 4.4 装备飞进暂存架（UIShopPanel.cs 733-905）

- 常量 `FLY_DURATION = 0.28f`、`FLY_LAYER_NAME = "Layer_FlyStash"`
- `captureStashLanding()` 在模型动手**之前**按 `m_itemViews[i] ↔ Model.Items[i]` 的下标对应关系，抄下中心 / IconSize / IconAngle 与 `m_stashCountBefore`
- 五个入口成对插入，`flyNewStashEntries()` 必须排在 `refreshBackpack()` 之前：`TryMovePlate`(354) / `TryRotatePlate`(368) / `TryStashPlate`(383) / `TrySellPlate`(402) / `TryStashItem`(478)
- `fillStorage()` 里 `m_flyingIn` 命中的那几件先 `SetEmpty()`，`finishFlight()` 落地才显形
- 飞行物是运行时 `new GameObject` 挂 `Image`（临时表现物，不是正式 UI，用户反感的是详情小窗那类被代码动态生成），`raycastTarget=false`，
  挂在面板 root 之后的独立一层，因此始终压在 `Panel_Backpack/Panel_Storage/Panel_Shop` 之上；`ensureFlyLayer()` 复用并 `SetAsLastSibling`
- 每帧按 `stashIndexOf(item)` 重算落点格子（架子中途重排也跟得上）；`flyer == null` 或下标 <0 就 break，面板关掉时 `stopFlights()` 直接销毁整层
- `RunBackpack.Stash` 是 `IReadOnlyList`，没有 `IndexOf`，另写了 `stashIndexOf()` 线性找（最多 5 件）

### 4.5 暂存格贴图占满

anchor 仍是 stretch ⇒ 实际占满 104x104；`preserveAspect` 保持 true（方格子里不做非等比拉伸）。商店卡 `Goods_Template/Img_Icon` 48x48 未动。
