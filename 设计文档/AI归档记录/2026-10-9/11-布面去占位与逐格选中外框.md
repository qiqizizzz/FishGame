## 二、用户诉求原话拆解

> 你怎么给空白布也加一个占位符，直接用下面那个就行啊，选中的时候可以用这俩个sprite
> （`Assets/Art/UI/Common/Sprite sheet for Basic Pack.png` 的 Button_select_brown 或 gray，
> 你看看怎么用比较好），选中的状态就套在每一个格子上面就好了（比如现在的那个 1x3 的空白画布，
> 在每一个底层的那个格子加一个选中外框，这样比较明显）

```text
① 空白布不该有自己的面子   → 布层退化成纯手势层，画面上的「布」就是被染色的格子
② 选中态画在格子上而不是布上 → 异形布的每一格都套一圈，轮廓立刻看得出来
③ 用给定的两个 sprite 二选一  → 取证 + 截图对比后定 gray（见 §五）
```

## 三、sprite 取证（别重跑）

```text
贴图      Assets/Art/UI/Common/Sprite sheet for Basic Pack.png  896x240  Point 过滤  px=100
工程内     没有任何 SpriteAtlas（全工程 0 个），子精灵直接 LoadAllAssetsAtPath 取
brown     rect=(180,67,24,25) border=(8,9,8,9)   亮部 #E8CFA6 暗部 #90625D
gray      rect=(148,67,24,25) border=(8,9,8,8)   亮部 #FBFBF6 暗部 #818B83
形状      逐像素 alpha 图确认：只有四角的 L 形括号有内容，
          center(12,12)=RGBA(0,0,0,0)、topedge(12,1)=0、leftedge(1,12)=0 → 中心与四边中段全空
结论      它是 selection reticle（四角括号），不是实心按钮底 → 正好用来「套」在格子上
```

**为什么用 `Image.type = Simple` 而不是 `Sliced`**：九宫格的 border 只有 8x9，`Sliced` 会把四角
原样贴出来、中间拉伸边框 → 括号缩成米粒大，等于看不见。`Simple` 把 24x25 整张拉到 130x130（约 5.4×），
因为过滤模式是 Point，放大后是干净的硬边像素块，不糊。

## 四、brown / gray 定稿：选 gray

用 3× 放大对照图（同一块 1x3 布选中，左边蓝色鱼竿格 + 右边米白布格各截一段）逐格看过：

```text
brown  米黄括号 + 暗紫棕描边 —— 和木色面板、米白布同色系，压在米白布上时亮部几乎融进布色，
       靠描边才分得开；往后高阶布若是暖色系，融色风险更大
gray   近白括号 + 冷灰描边 —— 蓝色鱼竿格、米白布格、土黄面板底三种背景上对比度都稳定，
       读起来就是「选中框」，不会误认成按钮
```

定 **gray**。字段仍是 `[SerializeField] private Sprite PlateSelectSprite`，
以后想换回 brown 在 Inspector 上拖一下就行，不用改代码。

## 八、★ 编辑模式拍 ScreenSpaceOverlay UI 的可行手法（下轮直接抄）

```text
为什么难  UIRoot Canvas = ScreenSpaceOverlay、worldCamera=null；Overlay 不画进任何 Camera.targetTexture
          Resources.FindObjectsOfTypeAll<Camera> 只有两个 SceneCamera（SceneView 的）→ screenshot-camera 拍不到
          screenshot-game-view / editor_application_get_state 在本会话没暴露给模型，别去调
          UnityEditor.GameView 反射只有 SetTargetDisplay/GetViewPixelRect/Repaint…，没有取图入口
```

```text
可行方案  1 rt = new RenderTexture(1080,1920,24,ARGB32); rt.Create()
          2 临时正交相机：orthographicSize=960、aspect=1080/1920、near=0.01、far=500、
            clearFlags=SolidColor、targetTexture=rt
          3 把 UIRoot 以外的场景根节点 SetActive(false)（layer 0=Default 没法用 cullingMask 分离）
          4 canvas.renderMode = ScreenSpaceCamera; worldCamera = 临时相机; planeDistance = 1f
            → scaleFactor 正好 1，world 单位 == 像素，Panel_Backpack 的 GetWorldCorners 直接换算裁剪矩形
          5 cam.Render() → RenderTexture.active = rt → Texture2D.ReadPixels → EncodeToPNG → File.WriteAllBytes
          6 复原：藏掉的根节点 SetActive(true)、相机与 rt DestroyImmediate/Release、canvas 改回 Overlay
          场景反正要 OpenScene(Single) 复原，中途随便脏，别 Ctrl+S 存场景
```

踩过的三个坑：

```text
1 GetRootGameObjects() 会把刚 new 出来的 __CaptureCam 也算成根节点 → 藏根时要排除自己，
  否则 DestroyImmediate 之后恢复循环会对已销毁对象 SetActive 抛异常
2 是 TextureFormat.RGB24，不是 Texture2D.RGB24
3 script_execute 里 IList 要写全 System.Collections.IList；字符串插值内的三元表达式必须加括号
```
