## 二、本轮开头那个 NullReferenceException

```text
堆栈    HookLateralMover.Advance:24 <- DescendingHookState.Update:36 / ReelingHookState.Update:30
        <- HookStateMachine.Update:62 <- FishingController.Tick:166 <- GameScene.Update:60
根因    HookLateralMover.cs:23 的 IFishingStats stats = runtime.Stats 拿到 null，
        第 24 行直接读 stats.LateralSpeed 就炸
出处    FishingController 里属性包的生成点排在 m_hook.Initialize(...) 之后，
        钩子在 Initialize 时就把 null 的 stats 攥进运行时；换一局还会攥着上一个已 Dispose 的旧包
修法    1 stats 生成点前移到 Initialize 之前
        2 新增 HookViewController.AttachStats(stats)，生成后立刻回注给钩子（视图不保管玩法状态）
        3 AttachStats 收到 null 时 QLog.Error 主动报错，不静默跳过
现状    用户自己 commit 成 18953fb「bug修复」，本轮没再碰这两个文件
```

## 三、e 步设计定案（为什么长这样）

```text
两层视图   新建 Layer_Cloths，父级 / anchor / pivot / sizeDelta / anchoredPosition 全部抄 Layer_Items，
           再 SetSiblingIndex 到 Layer_Items 前面 → 布垫底、装备在上，两层各自一套 rect
布的画法   异形展开成「每格一个 Img_Block（暗底满 pitch，不吃射线）+ 子 Img_Face（吃射线）」，
           Img_Face 只在没有邻居的那条边内缩 4px，接缝显出来，异形的轮廓一眼看得出来
命名       文本一律叫「布」，代码里用 Plate / Cloth，不再出现「纸页」
           （用户原话：图鉴只是给你看的，不是让你抄名字）

关键取舍：布不吃「单击旋转」
           装备沿用 UIShopItemView 的单击旋转，误点代价只是换个朝向
           布上压着装备，一转就可能挤掉别人；布还能卖金币，误点代价大得多
           → 点布只做「选中」，选中后浮出操作条：旋转 / 拆下 / 卖 N 金币
           → 点操作条背板空白、或再点同一块布 = 取消选中
           选中态只存在 UIShopPanel.m_selectedPlate 这一份，视图靠 IsPlateSelected 去问，不自存
```

### 4.4 卖布回收价

```text
ShopConfigSO   新增 [SerializeField, Range(0f,1f)] float ClothSellRatio = 0.5f + 只读属性 SellRatio
               ShopConfig.asset 已写入 ClothSellRatio: 0.5（走 SetDirty + SaveAssets 正规写入）
ShopService    新增 int SellPriceOf(IBackpackDef definition)
               只认 ClothPieceDef：基准买价 = CellBasePriceValue × Shape.CellCount × PriceScaleOf(稀有度)

               装备 / 非布 / 总表为 null 一律返回 0，等于「不回收」
```

## 八、待用户 Play 手测清单（UI 交互没法离线验）

```text
0 先退出 Play 再重进：面板脚本是本轮新写的，不换一局不会走上新代码
1 拖一块布换格子：空位就落；落点有别的布就弹回原位；被弹回来的路上挤掉的装备该出现在暂存架
2 点一块布 → 浮出「旋转 / 拆下 / 卖 N 金币」条；点条子空白处或再点同一块布 → 取消选中
3 找一块 2×2 的方形布 → 旋转按钮应该是灰的
4 卖一块压着装备的布 → 金币按半价进账、解锁格数变少、那件装备掉进暂存架
5 拆一块布进暂存架 → 再从架里点它 → 应该能取回来重铺；取不回就是软锁，算 bug
```
