## 三、改动内容

### 3.1 Assets/Prefabs/UI/UIShopDetailWindow.prefab

新增节点 `Img_DetailCoin`，**挂在 `Txt_DetailPrice` 底下当子节点**，而不是当兄弟节点：

| fileID | 组件 |
| --- | --- |
| 9182736450192837461 | GameObject `Img_DetailCoin`（layer 0，与兄弟节点一致） |
| 9182736450192837462 | RectTransform |
| 9182736450192837463 | CanvasRenderer |
| 9182736450192837464 | Image |

RectTransform：`anchorMin/Max = (0, 0.5)`、`pivot = (1, 0.5)`、`anchoredPosition = (-8, 0)`、`sizeDelta = (21, 30)`
→ 金币**右缘**贴在价钱 rect **左缘**外 8px，垂直居中。因为价钱 rect 会被代码收到「数字那么宽」，所以金币永远紧贴数字左边，不需要每帧重算位置。

Image：`m_Sprite = {fileID: -1512791694, guid: 313c8f1a053756d469eb09370f9c1f4f}`（= `Item_coin_white`）、`m_Type: 0`(Simple)、白色、`m_RaycastTarget: 0`、`m_Maskable: 1`。

顺带两处：
- `Txt_DetailPrice` 的 `m_Children: []` → 挂上新 rect（fileID 6248898138889214328 为其 RectTransform）
- 价钱文本 `m_text: "0 金币"` → `m_text: 0`，让编辑器预览与运行时口径一致

### 3.2 Assets/Scripts/UI/Shop/UIShopPanel.cs

| 位置 | 改动 |
| --- | --- |
| `DETAIL_PRICE_PATH` 注释 | 补一句「金币图是它的子节点，跟着价钱一起显隐，代码只负责把 rect 收到数字那么宽」 |
| 新常量 | `DETAIL_PRICE_COIN_WIDTH = 21f`、`DETAIL_PRICE_COIN_GAP = 8f`、`DETAIL_PRICE_TEXT_SLACK = 2f`（前两个必须与预制体那颗图对齐，改版式两边要一起动） |
| 商品详情写价钱处 | `m_detailPriceText.text = $"{entry.Price} 金币"` → `entry.Price.ToString()`；`SetActive(true)` 前插一行 `fitDetailPriceWidth()` |
| 新方法 `detailPriceBlockWidth()` | 金币宽 + 图字间隙 + 数字 preferredWidth，小窗定宽与名字行让位共用一个口径 |
| 新方法 `fitDetailPriceWidth()` | 把价钱 rect 宽收到 `GetPreferredValues(text).x + SLACK` |
| `setDetailNameReserve(...)` 调用 | 传参改为 `detailPriceBlockWidth() + DETAIL_PRICE_INSET_RIGHT + DETAIL_PRICE_GAP` |
| `detailWidth()` | `priceReserve` 从「只量文本宽」改调 `detailPriceBlockWidth()` |

**为什么必须 `fitDetailPriceWidth()`**：价钱 rect 在预制体里默认 96 宽、锚点钉在右上角，文本靠右对齐。金币图钉的是 rect **左缘**，rect 不收宽的话数字只有 4 位却留着一大截空白，金币会离数字老远。rect 是非拉伸锚点（(1,1)/(1,1)），所以 `sizeDelta.x` 就是宽度，可直接写。

## 四、设计取舍

- **金币不染红**：买不起时只把数字染成 `UIShopQuality.PriceUnaffordable`，金币保持原色。与商店 `UIShopGoodsItem` 一致（那边只在「已售出」时切换金币可见性，同样不染色）
- **靠父子关系而不是靠代码**：新增那颗图不进任何查找路径，`findDetailChild` 仍只找 name / desc / price 三个文本。价钱隐藏时金币自动跟着隐藏，代码零管理成本
- **不新增 SO、不新增贴图**：直接引用商店那颗 sprite 的 guid + fileID，避免又造一份重复资源

## 五、验证

1. **结构探针**（`script_execute`）：`rootChildren = Img_Face, Img_Accent, Txt_DetailName, Txt_DetailDesc, Txt_DetailPrice`；price / coin 均取到；`sprite=Item_coin_white type=Simple color=白 raycast=False`；`coin anchor(0,0.5) pivot(1,0.5) pos(-8,0) size(21,30)`；`price text='0' fs=30 align=MidlineRight`
2. **离屏渲染探针**：additive 空场景 + WorldSpace canvas + 正交相机 `Render()` + `ReadPixels` 出图 `Temp/detail_coin_check.png`，目检「🪙 1280」紧贴、垂直居中、不压名字行；探针收尾关场景后 `Game.unity` 仍 `IsDirty=false`、`RootCount=5`
3. **量过商店口径**：`UIShopPanel.prefab` 里 `Img_CoinIcon` 的 sizeDelta 就是 (21, 30)，两处一致
4. `assets_refresh` 后 Console 无项目报错（只剩探针自身的编译错）

### 踩坑记录（Unity 6 编辑器态）

- `SceneManager.CreateScene(name)` 编辑器下直接抛 `This can only be used during play mode`。改用 `EditorSceneManager.NewScene(NewSceneSetup.EmptyScene, NewSceneMode.Additive)` —— additive 才不会把当前打开的 Game 场景毁掉
- `Texture2D(w, h, UnityEngine.Rendering.TextureFormat.RGBA32, false)` 在本工程编译不过（该枚举在 `UnityEngine.Experimental.Rendering` 下），直接 `new Texture2D(w, h)` 即可
- 插值字符串里不能直接放三元表达式（`':'` 会终止插值），先取到局部变量再拼
- 本工程**不存在** `AssetDatabase.TryGetGUIDAndLocalFileID`、`Transform.GetChildren()`、`Sprite.GetLocalIdentifierForInstance`；`Texture2D.GetPixels32()` 只有无参重载
